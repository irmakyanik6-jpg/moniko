# MONIKO

Modern luxury women handbag website project.

## Technologies

- Next.js
- TailwindCSS
- React

## Features

- Responsive design
- Modern UI/UX
- Product showcase
- Mobile compatible
- Luxury brand interface

## Live Demo

https://irmakyanik6-jpg.github.io/moniko

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000/moniko](http://localhost:3000/moniko).

## Deploy (GitHub Pages)

```bash
npm run build
npm run deploy
```

GitHub repo Settings → Pages → branch `gh-pages`, folder `/ (root)`.

Live site: [irmakyanik6-jpg.github.io/moniko](https://irmakyanik6-jpg.github.io/moniko)
